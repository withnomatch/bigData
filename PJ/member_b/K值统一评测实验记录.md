# 成员 B：K 值统一评测实验记录

## 1. 实验目的

本次实验用于确定后续优化实验统一采用的聚类数 K。

早期 K 值选择主要依据轮廓系数、SSE/Inertia、簇规模分布等无监督聚类指标；本次收尾实验进一步引入 300 对人工标注问题对，评估不同 K 值对最终相似问题去重任务的影响。

因此，本次 K 值选择优先考虑去重任务指标，而不是只看聚类内部指标。

## 2. 实验输入与统一口径

统一输入样本：

```text
hdfs://10.176.62.230:9000/user/root/data/fixed_eval_sample_10pct_plus_300
```

样本构成：

```text
固定 10% 随机样本
+ 300 对标注数据涉及的问题
去重后用于 Spark 读取的记录数：15,813
```

统一标注数据：

```text
hdfs://10.176.62.230:9000/user/root/data/dedup_pairs_300_reviewed.csv
```

有效评测问题对：

```text
298 对
```

说明：原始标注文件为 300 对，其中 2 对在当前固定样本或聚类输出中未完整匹配，因此本次有效评测对数为 298。

## 3. 固定实验参数

除 K 值外，其余参数保持一致。

| 参数 | 设置 |
|---|---|
| 输入数据 | fixed_eval_sample_10pct_plus_300 |
| sample-ratio | 1.0 |
| 文本字段 | title + body |
| 特征方法 | TF-IDF |
| max_features | 5000 |
| min_df | 5 |
| KMeans max_iter | 30 |
| 相似度阈值 | 0.55 |
| 标签列 | reviewer_label |
| 正例标签 | 重复 |
| 负例标签 | 不相关、相关但不重复 |

测试 K 值：

```text
40, 45, 50, 55, 60, 80, 100, 130
```

## 4. 评测方法

每个 K 值完整执行一次：

```text
TF-IDF 特征构建
-> KMeans 聚类
-> 输出每个问题的 cluster_id 和 features
-> 用 300 对人工标注数据回查
-> 判断 question_id_1 和 question_id_2 是否同簇
-> 若同簇，再计算余弦相似度
-> 同簇且相似度 >= 0.55 时预测为重复
-> 计算 Precision / Recall / F1 / PR-AUC / Candidate Recall
```

Candidate Recall 的含义：

```text
真实重复问题对中，有多少对在聚类阶段被分到同一簇。
```

该指标非常关键，因为如果真实重复问题在聚类阶段已经被拆到不同簇，后续相似度阈值再怎么调整也无法找回。

### 5.2 去重率与候选保留情况

本表补充记录基准实验中没有单独命名输出、但可由评测指标推导得到的比例指标。

| 真实重复率 | positive_pairs / total_pairs | 标注数据中真实重复对所占比例 |

## 6. 结果分析

从 F1 看，K=45 和 K=60 并列最高，均为 0.3125。

但进一步比较 Candidate Recall 和 PR-AUC：

| 指标 | K=45 | K=60 |
|---|---:|---:|
| F1 | 0.3125 | 0.3125 |
| Candidate Recall | 0.5316 | 0.4304 |
| PR-AUC | 0.5332 | 0.5028 |

K=45 在 F1 不低于 K=60 的情况下，具有更高的 Candidate Recall 和 PR-AUC。

这说明 K=45 更能在聚类阶段保留真实重复问题候选，同时整体排序质量也更好。由于本项目最终目标是相似问题发现与问题去重，聚类阶段的候选召回非常重要，因此 K=45 更适合作为后续实验统一 K 值。

K=40 的 Candidate Recall 最高，为 0.5570，说明较小 K 更容易把真实重复问题放进同一簇。但 K=40 的 F1 为 0.2766，低于 K=45，说明其最终重复判定效果不如 K=45。

K=100 的 Precision 最高，为 0.9333，误报最少，但 Recall 和 F1 低于 K=45，整体更偏保守。

K=130 在早期轮廓系数粗测中表现较好，但在 300 对去重评测中 F1 没有提升，说明聚类内部指标最优不一定等价于最终去重任务最优。

## 7. 最终结论

后续实验统一采用：

```text
K = 45
```

正式表述：

```text
在统一固定样本和 300 对人工标注数据评测下，K=45 与 K=60 取得相同最高 F1，均为 0.3125。进一步比较发现，K=45 的 Candidate Recall 和 PR-AUC 均高于 K=60，说明其在保留真实重复问题候选和整体排序质量方面更优。考虑到本项目最终目标是相似问题发现与问题去重，后续优化实验统一采用 K=45。
```

## 8. 是否需要继续细测 K=41、42 等邻近值

当前不建议继续细测 41、42、43、44 等邻近 K 值，原因如下：

1. 本次收尾实验目标是确定后续统一实验 K 值，而不是做非常细粒度的 K 值调参。
2. 已测结果中 K=45 与 K=60 的 F1 并列最高，但 K=45 的 Candidate Recall 和 PR-AUC 更优，已经具备充分选择依据。
3. 每个 K 值都需要重新训练 KMeans 并重新评测，单个 K 耗时较长，继续细测 41-44 的收益不一定能覆盖时间成本。
4. 298 对有效标注数据规模较小，过度细测可能会对这批评测集产生过拟合，反而削弱结论稳健性。
5. K=45 同时具备较好的任务指标和较低解释成本，已经适合作为后续统一实验参数。
