# StackOverflow 问题去重聚类完整流程

本流程面向“将本质相同但表达不同的问题聚到一起”的任务，使用主目录下的
`oracle_database_questions_jsonlines.json` 作为输入数据。

## 流程

```text
读取 JSONLines 数据
-> 构造问答对文本 title + body + tags + top answers
-> HTML 清洗与文本规范化
-> TF-IDF 特征提取
-> K-Means 聚类
-> 簇内相似度计算
-> 输出疑似重复问题对
```

## 运行

先将数据上传到 HDFS：

```bash
hdfs dfs -mkdir -p /user/root/data
hdfs dfs -put oracle_database_questions_jsonlines.json /user/root/data/
```

运行完整流程：

```bash
./run_complete.sh
```

也可以手动运行：

```bash
spark-submit \
  --master spark://10.176.62.230:7077 \
  --driver-memory 2g \
  --executor-memory 4g \
  --executor-cores 2 \
  --num-executors 2 \
  complete_clustering.py \
  --input hdfs://node5:9000/user/root/data/oracle_database_questions_jsonlines.json \
  --output hdfs://node5:9000/user/root/output/complete_clustering \
  --k 50 \
  --max-features 5000 \
  --min-df 5 \
  --sample-ratio 0.1 \
  --dedup-top-per-cluster 80 \
  --similarity-threshold 0.55
```

## 输出

| 输出目录 | 说明 |
| --- | --- |
| `cluster_assignments` | 每个问题的聚类编号 |
| `cluster_summary` | 每个簇的问题数量 |
| `top_questions_per_cluster` | 每个簇中分数较高的代表问题 |
| `cluster_keywords` | 每个簇的高频关键词，可用于生成聚类标签 |
| `duplicate_candidates` | 同一簇内相似度较高的疑似重复问题对 |

## 关键参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--k` | `50` | K-Means 聚类数量 |
| `--max-features` | `5000` | TF-IDF 最大词汇表大小 |
| `--min-df` | `5` | 进入词汇表的最小文档频率 |
| `--sample-ratio` | `0.1` | 抽样比例，先跑通流程建议用 0.1 |
| `--dedup-top-per-cluster` | `80` | 每个簇内参与重复问题匹配的高分问题数 |
| `--similarity-threshold` | `0.55` | 余弦相似度阈值，高于该值输出为疑似重复对 |

## 展示建议

展示时重点说明：聚类不是最终去重结果，聚类用于缩小候选范围；真正用于去重的是
`duplicate_candidates` 中的高相似问题对。
