### 1. 数据情况说明：

本数据集来源于 Stack Overflow 官方数据公开项目 Stack Exchange Data Dump (SEDE)。原始 XML 文件为：

- `Posts.xml`：包含所有问题与回答（约 6000 万条）
- `Comments.xml`：包含所有评论（约 9100 万条）

数据由 Stack Exchange 官方 定期发布，本次数据集基于 2025-03-01 版本。

本数据集仅保留标签为 “oracle-database” 的问题与其对应的回答和评论，共计 152758 条。



### 2. 数据格式：

数据集为`.json`格式的文件，本 JSON 文件是一个 **问题列表数组**，每个元素表示一个与 `oracle-database` 相关的 Stack Overflow 问题，结构包括问题本身、其评论、对应的回答和回答的评论。

```数据格式
[
  { ... 第一条问题 ... },
  { ... 第二条问题 ... },
  ...
]
```

每一个元素格式如下：

```数据点格式
{
  "question_id": "问题id",
  "title": "问题标题",
  "body": "问题内容",
  "tags": [
    "问题标签1",
    "问题标签2"
  ],
  "score": 打分（得分越高，代表该问题/回答/评论质量越高，得分由用户给出，旁边有赞成和反对，每有人点一次赞成加一分，反对减一分）,
  "comments": [
    {
      "body": "评论内容",
      "score": 打分
    }
  ],
  "answers": [
    {
      "answer_id": "回答id",
      "body": "回答内容",
      "score": 打分,
      "comments": [
        {
          "body": "对回答的评论",
          "score": 打分
        },
        {
          "body": "对该回答的第二条评论",
```

### 3. 数据读取：

一次性读取：

```

with open("your_path/oracle_database_questions.json", "r", encoding="utf-8") as f:
    data = json.load(f)
```
