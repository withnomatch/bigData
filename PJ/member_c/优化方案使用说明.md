# 特征提取优化方案使用说明

## 优化内容概述

本方案针对基准方案的TF-IDF特征提取进行了以下优化：

### 1. TF-IDF参数优化
- **词汇表大小**: 3000 - 10000（网格搜索）
- **最小文档频率**: 3 - 10（网格搜索）
- **最大文档频率**: 0.8 - 0.95（网格搜索）
- **参数网格搜索**: 64种参数组合对比实验

### 2. 文本预处理优化
- **定制停用词列表**: 包含150+Oracle数据库专业停用词
- **词形还原**: 基于规则的词形还原（复数、过去式、进行时）
- **专业术语识别**: 识别并保留100+Oracle数据库专业术语

### 3. 对比实验输出
- 自动生成参数对比表格
- 保存所有实验结果JSON文件
- 自动选择最佳参数组合

## 运行方式

### 方式1：参数网格搜索（推荐）

自动测试64种参数组合，找出最佳参数：

```bash
spark-submit \
    --master spark://10.176.62.230:7077 \
    --driver-memory 2g \
    --executor-memory 4g \
    --executor-cores 2 \
    --num-executors 2 \
    /root/optimized_clustering.py \
    --input hdfs://node5:9000/user/root/data/oracle_database_questions_jsonlines.json \
    --output hdfs://node5:9000/user/root/output/optimized_clustering \
    --k 50 \
    --sample-ratio 0.1 \
    --grid-search
```

**注意**: 网格搜索会运行64次实验，耗时较长（约3-5小时）。建议先用小数据采样测试。

---

### 方式2：单次运行（指定参数）

使用指定参数运行单次实验：

```bash
spark-submit \
    --master spark://10.176.62.230:7077 \
    --driver-memory 2g \
    --executor-memory 4g \
    --executor-cores 2 \
    --num-executors 2 \

    --input hdfs://node5:9000/user/root/data/oracle_database_questions_jsonlines.json \
    --output hdfs://node5:9000/user/root/output/optimized_clustering_single \
    --k 50 \
    --sample-ratio 0.1 \
    --vocab-size 7000 \
    --min-df 7 \
    --max-df 0.9
```

## 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--grid-search` | False | 是否运行参数网格搜索 |
| `--vocab-size` | 5000 | 词汇表大小（单次运行） |
| `--min-df` | 5 | 最小文档频率（单次运行） |
| `--max-df` | 0.9 | 最大文档频率（单次运行） |
| `--sample-ratio` | 1.0 | 数据采样比例 |
| `--k` | 50 | 聚类数量 |

## 预期优化效果

根据Oracle数据库领域特点，预期优化效果：

1. **词汇表优化**: 专业术语识别提高特征质量
2. **停用词优化**: 移除无关词汇，提高聚类精度
3. **参数优化**: 自动找到最佳TF-IDF参数组合
4. **聚类质量**: 轮廓系数预期提升10-20%

---

## 注意事项

1. **网格搜索耗时**: 64种参数组合，建议先用小数据测试
2. **内存需求**: 增加词汇表大小需要更多内存
3. **Python兼容**: 代码兼容Python 2.7和Spark 2.0
4. **专业术语**: 可根据需要扩展ORACLE_DOMAIN_TERMS列表

## 扩展建议

可根据实际需求进一步优化：

1. **扩展专业术语**: 添加更多Oracle数据库术语

3. **添加更多预处理**: 如同义词合并、拼写纠错等
4. **集成NLTK**: 如有Python 3环境，可使用NLTK词形还原
