# PPT 基准实验部分

## 第1页：研究任务与基准思路

**标题：先建立可复现基准，再判断优化是否有效**

- 任务：将语义相近的 StackOverflow Oracle 问题聚到同一组；
- 数据规模：152,758 条问题；
- 基准方法：标题与正文 → TF-IDF → KMeans；
- 基准价值：提供统一的数据、参数、随机种子和评价口径。

## 第2页：基准实验流程

**标题：基准链路覆盖了从原始文本到聚类结果的完整过程**

```text
JSONLines → HTML 清洗 → title + body → 分词与停用词
→ CountVectorizer + IDF → L2 归一化 → KMeans（K=50）
```

参数：10% 固定抽样、seed=42、词表 5,000、minDF=5、最大迭代 30。

## 第3页：实验结果

**标题：流程成功跑通，但 38.28% 的样本集中在单一大簇**

| 指标 | 数值 |
| --- | ---: |
| 样本数 | 15,344 |
| 聚类数 | 50 |
| 最大簇 | 5,874 |
| 最大簇占比 | 38.28% |
| 最小簇 | 1 |
| 簇大小 CV | 2.6609 |
| 归一化簇熵 | 0.7227 |
| KMeans 耗时 | 1,463.21 秒 |
| 总耗时 | 1,894.24 秒 |

建议图表：左侧画簇大小 Top10 横向条形图，右侧突出 `38.28%` 和 `31.6 min`。

## 第4页：基准结论与优化路线

**标题：基准证明流程可行，也定位了质量与性能瓶颈**

- 质量瓶颈：领域通用词导致主题区分度不足；
- 数据瓶颈：只使用 title 和 body，缺少 tags 与高分回答；
- 参数瓶颈：K 固定，缺少参数搜索；
- 性能瓶颈：KMeans 占总耗时约 77.2%，特征未缓存。

优化路线：领域停用词 → 标题和标签加权 → 加入回答 → K 参数搜索 → 簇内余弦相似度去重。
