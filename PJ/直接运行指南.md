## 快速开始（已部署环境）

如果环境已经部署好，按以下步骤运行：

### 1. 连接集群

```bash
ssh root@10.176.62.230
# 密码: Fdwangp123
```

### 2. 启动服务

```bash
# 启动HDFS
/opt/hadoop/sbin/start-dfs.sh

# 启动Spark Master
/opt/spark-2.0.0-bin-hadoop2.7/sbin/start-master.sh

# 启动Spark Workers
ssh root@10.176.62.231 "/opt/spark-2.0.0-bin-hadoop2.7/sbin/start-slave.sh spark://10.176.62.230:7077"
ssh root@10.176.62.232 "/opt/spark-2.0.0-bin-hadoop2.7/sbin/start-slave.sh spark://10.176.62.230:7077"

# 验证
jps
```

### 3. 运行任务

```bash
export SPARK_HOME=/opt/spark-2.0.0-bin-hadoop2.7

spark-submit \
    --master spark://10.176.62.230:7077 \
    --driver-memory 2g \
    --executor-memory 4g \
    --executor-cores 2 \
    --num-executors 2 \
    /root/baseline_clustering.py \
    --input hdfs://node5:9000/user/root/data/oracle_database_questions_jsonlines.json \
    --output hdfs://node5:9000/user/root/output/baseline_clustering \
    --k 50 \
    --max-features 5000 \
    --sample-ratio 0.1
```

### 4. 查看结果

```bash
hdfs dfs -ls /user/root/output/baseline_clustering
hdfs dfs -cat /user/root/output/baseline_clustering/cluster_summary/*
```

### 5. 停止服务

```bash
# 停止Workers
ssh root@10.176.62.231 "/opt/spark-2.0.0-bin-hadoop2.7/sbin/stop-slave.sh"
ssh root@10.176.62.232 "/opt/spark-2.0.0-bin-hadoop2.7/sbin/stop-slave.sh"

# 停止Master
/opt/spark-2.0.0-bin-hadoop2.7/sbin/stop-master.sh

# 停止HDFS
/opt/hadoop/sbin/stop-dfs.sh
```
