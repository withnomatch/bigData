# 全组实验设计与优化路线汇总

## 统一实验口径

为保证各成员结果可横向比较，所有实验应尽量固定：

| 项目 | 统一设置 |
| --- | --- |
| 数据 | `oracle_database_questions_jsonlines.json` |
| 抽样 | 10%，随机种子 42 |
| 默认 K | 50，成员B除外 |
| 基准特征 | title + body，TF-IDF，L2 归一化 |
| 基准参数 | vocabSize=5000，minDF=5，maxIter=30 |
| 集群 | Spark 2.0，Master `10.176.62.230`，Workers `231/232` |
| 必报指标 | 样本数、训练时间、总时间、最大簇占比、簇大小 CV、簇熵 |
| 可选指标 | WSSSE、近似轮廓、人工语义一致性 |

Spark 2.0 没有 `ClusteringEvaluator`。如使用自定义或近似轮廓系数，必须明确标注算法和抽样数量，不能与 Spark 官方轮廓系数混称。

## 优化路线

```text
基准 TF-IDF + KMeans
├─ B：搜索 K=40~60
├─ C：优化 TF-IDF 参数与文本预处理
├─ D：替换或融合 Word2Vec 语义特征
├─ E：更换聚类结构并进行小簇合并、标签生成
└─ F：优化初始化、距离、迭代次数与多次运行
```

建议最终组合顺序：

1. 以成员B选出的 K 作为统一聚类数；
2. 采用成员C或D中表现最好的特征方案；
3. 采用成员F推荐的执行参数；
4. 对比成员E的 KMeans/BisectingKMeans；
5. 对最终结果执行小簇合并和标签生成。

## 当前可用结论

### 基准方案

- 15,344 条样本，K=50；
- 最大簇占比 38.28%；
- 簇大小 CV 2.6609，归一化簇熵 0.7227；
- KMeans 训练 1,463.21 秒，总耗时 1,894.24 秒。

### 成员F

- 原始 TF-IDF 欧氏距离实验 F03 出现 99.02% 超大簇和 36 个单点簇，属于退化结果；
- 不应只按近似轮廓系数选择 F03；
- 综合质量、分布与时间，采用 F01：
  `random + cosine等价特征 + maxIter=20 + seed=42`；
- F01 训练时间 16.76 秒，最大簇占比 19.72%，无单点簇。
