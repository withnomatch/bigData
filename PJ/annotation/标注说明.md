# 问题对去重标注说明

`dedup_pairs_initial.csv` 是机器辅助初标数据，不应直接作为最终金标准。

## 标签定义

- `重复`：两个问题的核心目标、输入条件和期望答案基本相同，答案可以相互替代。
- `相关但不重复`：属于相同主题或错误码，但环境、操作对象、约束条件或期望答案不同。
- `不相关`：核心技术主题和解决目标不同。

二分类评估中，只有“重复”记为 `1`，其余两类都记为 `0`。

## 人工复核

1. 同时阅读两个标题、正文摘要和标签。
2. 在 `reviewer_label` 填写最终标签。
3. 在 `reviewer_name` 填写姓名。
4. 有争议时在 `review_notes` 说明原因，并由另一名成员复核。
5. 只有 `review_status` 改为“已复核”的记录才能进入最终测试集。

不要因为两个问题拥有相同 Oracle 错误码就直接判定重复。同一错误码可能由完全不同的程序环境和输入条件触发。
